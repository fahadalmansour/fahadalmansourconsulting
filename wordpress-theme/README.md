# Fahad Almansour Consultant Office (FSC) - WordPress Theme

A professional bilingual (EN/AR) WordPress theme for IT Decision Advisory services.

## Quick Install

1. Download `wordpress-theme.zip`
2. Go to WordPress Admin → **Appearance → Themes → Add New → Upload Theme**
3. Select the zip file and click **Install Now**
4. Activate the theme

## Features

- Bilingual support (English/Arabic with RTL)
- Custom logo support
- Social media integration (LinkedIn, Twitter/X, YouTube)
- Cookie consent with GDPR compliance
- Google Analytics / GTM / Meta Pixel ready
- Contact form shortcode
- Modern, professional design
- Smooth animations

## Customizer Settings

Go to **Appearance → Customize** to configure:

| Section | Options |
|---------|---------|
| **Site Identity** | Logo, Site Title, Tagline, Favicon |
| **Social Media Links** | LinkedIn, Twitter/X, YouTube URLs |
| **Tracking & Scripts** | GA4 ID, GTM ID, Meta Pixel ID |

## Shortcodes

Use these in any page/post:

```
[fsc_hero]
[fsc_how_we_work]
[fsc_decision_areas]
[fsc_advisory_services]
[fsc_contact_form]
[fsc_social_links]
[fsc_why_us]
[fsc_latest_insights]
```
